# Theoretical Computer Science — Independent Study

An 8-week self-directed study focused on the core topics of Saarland University's Introduction to Theoretical Computer Science lecture.

## Scope
- Formal Languages
- Automata Theory
- Computability
- Decidability
- Complexity Theory
- NP-Completeness
- Reductions

## Method
For each topic:
Theory
→ Formal Definition
→ Example
→ Proof / Reasoning
→ Implementation where appropriate
→ Exercises
